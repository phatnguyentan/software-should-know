# Frontend Roadmap theo Domain Knowledge System

Roadmap này tập trung vào năng lực frontend engineering bền vững thay vì chỉ học framework.

## Nguyên tắc
- CORE trước PRACTICE.
- Tư duy product + UX + performance + reliability.
- Frontend là một phần của system, không tách rời backend/domain.

## Stage 1 — Core Foundations
1. HTML semantics + accessibility
2. CSS layout systems + responsive design
3. JavaScript fundamentals + async model
4. Browser/runtime/web fundamentals

## Stage 2 — Software Engineering Core
1. Component design + state management
2. API integration contract-first
3. Error handling + loading + empty-state patterns
4. Frontend testing baseline (unit/component/e2e)

## Stage 3 — System & Product Integration
1. Frontend architecture (feature modularity)
2. Performance (latency/bundle/render/profile)
3. Observability (logs/metrics/session traces)
4. Security basics (XSS/CSRF/token handling)

## Stage 4 — Practice Layer
1. Framework ecosystem (React/Vue/Angular)
2. Build/deploy/CDN/caching strategy
3. Design system + theme system + consistency

## Stage 5 — AI-Native Frontend
1. AI UX patterns
2. Agent/UI orchestration
3. Guardrails + verification cho AI output trong UI flow

## Classification (Frontend)
- 🟢 CORE: web fundamentals, architecture, testing, security principles
- 🔵 PRACTICE: framework/build/deployment ecosystem
- 🟣 AI-NATIVE: AI-first UX and workflows
