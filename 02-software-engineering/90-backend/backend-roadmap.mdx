# Backend Roadmap theo Domain Knowledge System

Roadmap này thay thế cách học backend theo danh sách tool rời rạc.

## Nguyên tắc
- Ưu tiên **CORE** trước **PRACTICE**.
- Học theo flow: **Problem → Design → Implementation → Quality → Operations**.
- AI là lực khuếch đại, không thay nền tảng backend engineering.

## Stage 1 — Core Foundations
1. HTTP/HTTPS, DNS, TCP/IP
2. OS fundamentals (process/thread/memory)
3. Programming fundamentals + data structures
4. SQL fundamentals + transaction/isolation/index

## Stage 2 — Software Engineering Core
1. Requirement modeling và domain modeling
2. API design (REST + idempotency + versioning + error model)
3. Clean implementation, refactoring, code review
4. Testing strategy (unit → integration → contract → e2e)

## Stage 3 — System Design
1. Modular monolith trước microservices
2. Messaging patterns (queue/pub-sub/outbox/inbox)
3. Distributed failure handling (timeout/retry/circuit breaker)
4. Scalability + reliability + observability

## Stage 4 — Run / Operations
1. CI/CD baseline
2. Cloud fundamentals (compute/storage/network)
3. Security baseline (authn/authz/secrets/audit)
4. Incident response và production verification

## Stage 5 — AI-Native Backend
1. LLM integration patterns
2. RAG + tool calling + context/memory
3. Evaluation/guardrails
4. AI verification workflow: **Generate → Verify → Integrate**

## Classification (Backend)
- 🟢 CORE: protocol, OS/network, database, design/testing, distributed principles
- 🔵 PRACTICE: framework/cloud/CI/CD stack
- 🟣 AI-NATIVE: LLM orchestration trong backend workflow
